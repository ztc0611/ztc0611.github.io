Two decisions behind the board.

Aweigh turns public ferry feeds into a departure board. These two examples show the decisions behind what stays on screen.

Two sailings at 12:20. One was cancelled.

On June 1, 2026, the 12:20 PM from Bremerton was cancelled. The 12:20 PM from Seattle was still running. Matching by clock time alone would cross out both.

Where this comes from

Two public WSDOT schedule feeds, read on June 1, 2026: the day's running schedule, recorded at 10:30 AM Pacific, and the day's schedule adjustments, recorded at 7:05 AM Pacific. Both were captured by a Raspberry Pi that polls the public API and keeps the responses.

A schedule adjustment stores its time separately from its service date. The terminal and departure-or-arrival indicator establish which direction it applies to. Aweigh combines those fields to match the directed terminal pair and an exact departure instant.

How long should a missing number stay on screen?

If the capacity feed is completely empty or a request fails, Aweigh temporarily keeps the last good value. Once that value is more than five minutes old, it shows unknown capacity.

The rules underneath

The limit is inclusive. A value exactly five minutes old is still shown; a value older than that is not.

A nonempty response that leaves one terminal out is a different case. Nothing is held for that terminal, so its sailings show unknown capacity straight away.

Service alerts follow the opposite rule. An alert request that succeeds and returns nothing is taken at face value, because an alert leaving the feed is how it gets cleared. Only a request that fails falls back to the previous list. For capacity, both a completely empty feed and a failed request use the temporary fallback.

This describes Aweigh's direct-to-WSDOT client, the path an Apple Watch uses on its own. The server path applies the same five minute limit before it hands capacity to the app.

Test matrix

The happy path is only one case.

Aweigh's watch interface is tested across screen sizes and the situations ferry riders actually encounter: delays, cancellations, low tides, changing capacity, and the last sailing of the day.

Location needs context.

The nearest terminal isn't always the right one.

On southeast Orcas Island, Lopez terminal is closer in a straight line than Orcas terminal, even though reaching Lopez requires another ferry. Aweigh uses island boundaries instead of distance alone, so it selects the terminal connected by road.

Schedules, vessel positions, and camera feeds are sourced from WSDOT's public APIs.
