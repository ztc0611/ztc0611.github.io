# Living poster

An oversized name printed over a reflective silver-blue surface. The water is the opening composition, with project imagery in ordinary document flow beneath it.

Palette: ice #dae5eb, silver #b8cedb, blue #668fa8, deep ink #18394c, white #f7fafb. Helvetica Neue has compact, broad display lettering and a quiet readable body scale. All primary text aligns to the same responsive inset. The two name lines share a left edge; neither moves with the pointer.

The opening is a single uninterrupted viewport. Header, name, and footer establish three horizontal positions. The main work uses large unboxed media and ordinary scrolling; supporting projects become a compact image grid. This avoids another fictional object enclosure and gives the actual app interfaces their own space.

Motion: bounded local wave impulses, continuous phase while active, smooth decay to exact zero, no idle loop, no custom cursor, no hover geometry changes. Native anchor navigation and document flow. Pause offscreen and when the document is hidden. Reduced motion draws the still material and suppresses impulses. Canvas resize changes backing resolution without changing layout. The fallback is the same palette with static reflected light.
