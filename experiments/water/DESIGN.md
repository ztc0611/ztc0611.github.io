# Water study

Palette: sea glass #e2f0e9, deep ink #163c45, pool blue #74b9c2, reflected sun #fff4c7, porcelain #f8fbf7. After-hours variant: deep blue #16384d, silver #cddcde, illuminated aqua #5babad.

Type: Georgia as a large, closely spaced name; system sans for prose and controls. The name functions as the composition's fixed landmark. No small uppercase labels or decorative numbering.

Layout: a full-width interactive water surface sits behind a quiet left-aligned introduction. Three project buttons along the lower edge select a physical-looking image floating at the right. Real links and a readable project list continue below.

    navigation
    name                    project artifact
    introduction            on the water
    project selector        light / water controls
    concise selected-work list

Critique: a gradient blob behind type would be generic. Use a refractive WebGL surface with a visible tiled bottom and pointer-generated wave normals instead. Material response is the main event, with no continuous motion once the water settles. Project selection is conventional and keyboard accessible. The footer identifies native assets versus atmospheric interaction. This is a design study, not an app replica.
