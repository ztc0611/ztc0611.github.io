# Fresh portfolio directions

Open `/experiments/fresh/` on the repository's local HTTP server to compare:

- `../instrument-desk/`: a new precision desk with working physical instruments.
- `../working-folio/`: a new tactile presentation folio with project specimens.

These designs start independently from the earlier Objects studies. They reuse portfolio facts and project media, while their layouts and physical objects are designed anew. Existing experiments remain available.

The refinements to evaluate are physical coherence, clear action and outcome, a readable portfolio beyond the interactive opening, and working desktop/phone layouts.
